Panduan Kontrol

Pilih cara bermain yang paling nyaman: mouse, layar sentuh, keyboard, atau controller.

Kamera & Mouse / Sentuh

  • Putar kameraSeret kiri / 1 jari
  • Geser kamera (pan)Seret kanan / Shift + seret / 2 jari
  • Zoom masuk / keluarScroll / Cubit 2 jari
  • Pusatkan kameraC atau tombol bidik
  • Susun & hapus blokKlik tambah · Seret atur / buang

Keyboard

  • Pindah fokus menu & blok↑ ↓ ← → / Tab
  • Pilih / masuk wadahEnter / Spasi
  • Geser kamera / pusatkanW A S D / C
  • Geser urutan blokAlt + ↑ / Alt + ↓
  • Hapus blok terpilihDelete / Backspace
  • Jeda / kembali / keluar wadahP / Esc
  • Buka panduan kontrol? / H

Controller / Gamepad (Xbox / PlayStation)

  • Pindah fokus menu & blokD-pad / Stik Kiri
  • Pilih / aktifkanA (✕)
  • Kembali / keluar wadah / jedaB (○)
  • Jalankan programY (△)
  • Minta petunjukX (□)
  • Geser blok naik / turunLB / RB (L1 / R1)
  • Jeda / PengaturanStart (Options)
  • Editor LevelD-pad kursor · tahan RT (R2) melukis

Catatan: Kontrol kamera (putar, geser, zoom) menggunakan mouse, layar sentuh, atau tombol WASD & C di keyboard.

Editor Level (Keyboard): 1–9, 0, - pilih alat · Shift + Panah melukis · Ctrl + Z / Y undo/redo · Ctrl + Enter uji level.
