Seorang kesatria kehilangan penglihatannya. Kamulah matanya.

Eyes for the Nameless adalah game puzzle pemrograman 3D untuk belajar berpikir komputasional. Susun blok perintah, yaitu Maju, Belok, Lompat, Ulangi, Jika, Tarik Tuas, Tunggu, dan Fungsi, untuk menuntun kesatria buta keluar dari kastil, dibimbing suara sang putri.

✦ Tema: STEM Education

Sub-tema: Sebab Akibat & Satu Langkah Kecil

  • Satu langkah kecil. Setiap blok adalah satu langkah kesatria. Masalah besar, yaitu keluar dari kastil, dipecah menjadi langkah-langkah kecil. Materinya juga bertahap: satu konsep baru di setiap bab.
  • Sebab akibat. Setiap perintah punya akibat yang langsung terlihat. Menarik tuas (sebab) menurunkan jembatan (akibat). Sensor putri menentukan tindakan berikutnya. Saat program gagal, game menunjukkan blok penyebab dan akibatnya, sehingga pemain belajar menelusuri kesalahan kembali ke sumbernya.

✦ Yang dipelajari

  • Bab I · Menara Atas: urutan perintah (sequence) · struktur bangunan
  • Bab II · Lorong Perpustakaan Tua: perulangan (loop) · pola & efisiensi
  • Bab III · Ruang Mesin Jam: percabangan (if/else) + sensor · sistem kontrol
  • Bab IV · Ruang Bawah Tanah: fungsi (prosedur) · modularitas
  • Bab V · Gerbang Kastil: gabungan semua konsep + debugging · perbaikan sistem

✦ Fitur

  • 5 bab bercerita dengan plot twist
  • 3 bintang per bab berdasarkan waktu menyusun
  • Petunjuk putri bertingkat dan kamus blok
  • Umpan balik Sebab → Akibat setiap kali program gagal
  • Editor level custom yang bisa dibagikan lewat kode
  • 3 slot simpan profil
  • Aksesibilitas: ukuran teks, kontras tinggi, font mudah dibaca, kurangi animasi, kontrol penuh keyboard & gamepad

✦ Kontrol

Mouse / sentuh

  • Klik blok di Kitab Perintah untuk menambahkannya ke program
  • Seret blok untuk mengatur urutan; seret ke luar program untuk menghapus
  • Klik Jalankan untuk menjalankan program
  • Seret dunia 3D untuk memutar kamera, klik kanan / Shift+seret (atau 2 jari) untuk menggeser kamera, scroll untuk zoom, klik ikon bidik untuk memusatkan kamera

Keyboard

  • Panah: pindah fokus · Enter / Spasi: pilih · Esc: kembali / jeda · P: jeda permainan
  • W/A/S/D: geser kamera · C: pusatkan kamera · Delete: hapus blok · Alt + ↑/↓: geser blok · Enter pada Ulangi/Jika: masuk ke isi blok
  • Editor level: 1–9, 0, - pilih alat · Shift + panah menggambar · Ctrl+Z / Ctrl+Y undo/redo · Ctrl+Enter uji coba

Gamepad

  • D-pad / stik kiri: pindah fokus · A: pilih · B: kembali
  • Y: jalankan program · X: petunjuk · LB/RB: geser blok · Start: jeda / pengaturan
